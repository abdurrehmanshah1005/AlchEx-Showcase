AlchEx — Student Exchange Platform

AlchEx is a full-stack student exchange platform designed to enable university students to exchange goods and services through a secure, interactive marketplace.

Developed collaboratively as a Database Systems project at FAST-NUCES Lahore, the platform combines modern web technologies with relational database management.

Key Features

- Student authentication and account management
- Product listings and exchange management
- Trade proposals and negotiations
- Real-time communication using WebSockets
- Role-based access control
- Relational database integration
